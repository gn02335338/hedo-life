# 暴走、成就與尾牙

這次新增的規則只由 `e13-` 新局啟用；v3 匿名身分、圖鑑、存檔與既有重播格式保留。e12 的 234 條自然路線在修改前先保存，10,172 個直接操作檢查點與對應 JSON 存檔檢查點均需保持原雜湊。

## 卡通暴走

「受不了了，扁他」可從報到、工作、人事、PIP、離職、休息、尾牙及非終局結果開啟。玩家選八位角色之一；反應取決於自己的心情、老闆心情、角色是否在場及種子亂數。只在確認對象後抽籤，開關選單不會重抽。每工作回合只有第一次出手會結算，後續可進入但只提供免費收手。已選定的結局不能撤回。

暴走是一段抱枕、漫畫煙霧與辦公室荒謬的虛構插曲。結果可能出氣、撲空、被留下紀錄、吃癟，或由人事接手。退出時保留原通知、PIP 倒數與各層返回位置；若從結果頁開始，上一選擇先照正常流程結算，無額外工作日。

## 32 枚圖文成就

每枚都有原創 SVG 插畫、名稱、敘述、日期與來源標示。未解鎖的名稱、圖案與條件不公開。成就涵蓋日常、職涯、PIP、紓壓、八位角色的暴走、特定結果與尾牙。

成就先保存於瀏覽器，再送可重播的操作前綴驗證。伺服器只存成就 ID、首次取得時間、人生編號、匿名歸屬與種子雜湊；不留原始種子或操作。未離場也能同步，且不增加完成局數。離線時保留每局最新證據重試；匯入圖鑑的成就標成「匯入收藏」，不能靠 JSON 裡的 `verified` 自稱已驗證。

## 尾牙之夜

尾牙在工作中後段隨機出現，最多一場、三個階段，讓緊急人事與 PIP 優先。進場、抽獎、散場各有四種選項與選後結果。抽獎有大獎、小獎與空手而回；選前不顯示權重或數值效果。

使用的史冊靈感包含尾牙點歌、First Love 搶麥、Rick 紅白穿搭的賭盤、抽獎後請飲料，以及餐會上的預算與 NASDAQ 話題。對白、獎項、機率、互動與後果另行創作。阿良「答應暗黑續攤，最後自己消失」依使用者指定，兩個邀請選項都固定發生，不因此扣款。私人頁面、原文、網址與人物私事留在私人研究資料夾。

- 全部 234 種新版結局以自然操作搜尋並重播；沒有注入能力、職級、旗標或亂數。
- 234 條 e12 舊路線與所有直接／JSON 檢查點保持一致；更早版本的既有測試照常執行。
