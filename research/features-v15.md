# 科系爭議、顧問支線與夢境辨識

新局使用 `e15-` 種子。結局仍是 288 種、成就仍是 38 枚，日常事件由 205 增加為 209 個。

學歷事件依實際台詞處理：本科不符優先回應科系；沒有本科落差但被嫌校名時，保留校名選項；單純文組或學位偏見則回應該背景。科系分支可選「馬上報考台大電機，找林澤教授當指導老師」，結果僅表示送出申請及詢問，不把錄取或指導寫成已確定。拿出交付紀錄的回應也依抱怨內容改寫，不再在科系爭議裡突然說他只看校名。

四個顧問事件涵蓋 Wi-Fi 救火、介紹教授與留任、研究問題變開發排程，以及進修被當成公司 KPI。前兩個場景參考私人史冊的情境，其餘為原創延伸；所有角色台詞、研究與申請流程都是遊戲創作。沒有發布私人原文或連結，也沒有把史冊作者對教授身分的推測改寫成已查證事實。事件由既有 Wing、Rick、Sonny 說話，延續直接針對當下對話者的暴走規則。

夢境文案移除不通順的漫畫、字幕和對話框比喻。揭曉後的結果卡以淡紫雲霧、月亮及「腦內夢境／現實沒有動手」標示，可按「回到現實」接續故事；真失控使用另一種標記與「面對後續」。兩種介面都不在選前出現。背鍋紀錄依每筆已發生的結果分類，不會因為先前做過夢，就把後來真的失控標成夢境。減少動畫設定會停用雲霧移動。

既有 e14 的教育選項及歷史保留，避免把玩家當時選過的紙箱校門改寫成報考。舊夢境只修飾顯示用的固定句子，原始存檔和重播資料不變。數值、機率、匿名身分與資料庫欄位不變。

驗證包含 191 項測試、288 條 e15 自然結局路線，以及 292 條 e14 結局／功能路線的 10,931 個直接與 JSON 檢查點比對。四個顧問事件均在自然路線出現，暴走對象、即時存檔及伺服器重播通過。另以 143 種文字組合比對，確認八角色／時機／觸發階段及教育理由的文字層不改變機制。本機 Worker API 實測保留舊版流程與新版完成紀錄、成就驗證、擁有權、防偽造及重送不重複計數。

桌面與手機實際試玩 MIS 的跨科系履歷，遇到爭議後選擇報考、在結果頁觸發夢境，再醒來接續原先的降薪通知，確認原選擇沒有重算。截圖及私人研究證據留在忽略目錄，未隨原始碼公開。
