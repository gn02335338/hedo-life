# 財務、會計、人資與行政（e28）

新人生增加財務專員、會計專員、人資專員、行政專員，合計十三種職業。高階主管仍藏在隨機職業內。四個職業各有助理、專員、資深、主任、副理、經理、總監與首長八階職涯，面試薪資、助理任用及職涯評核沿用既有抽籤和能力取捨。

人資與行政在報到時可能互相改派；任職中的跨職務工作則寫成事件，保留原本的主要職稱。財務處理資金、付款與應收，會計處理憑證、核銷與月結，人資面對招募、考核、咖啡及行政雜務，行政處理採購、接待、設備及臨時人事工作。四職業各有八場原創情境，共 32 場、96 個回應；每場至少一個腦洞選項。七場明確多人對話可從在場角色中選擇暴走對象，分機改碼那場共有四位；事件前與結果後都核對目標，不把提到或不在現場的人放進名單。

素材取自私人史冊中的行政／人資職務混用、咖啡交辦、財務兼任、帳務交接及表單版本等記憶。角色對白、情節組合、數字及結果均為遊戲創作。史冊對財務與會計技術工作的記載較少，因此這部分補成原創職務情境，不視為特定公司真實帳務或人事紀錄。原始文章、私人題庫及研究索引不放入公開版本。

職業事件依實際職務抽取，保留原有優先排程與避免重複的規則。PIP、人事、降薪、崩潰與休息仍有各自的優先順序。未選擇前不顯示機率與結果，結算後才顯示實際增減。新增四職業各有 42 種可達結局，共增加 168 張，圖鑑合計 545 張；原有 377 張的 ID 與順序保留。成就仍為 122 枚，角色仍為十六位。

舊 e27 的 377 條自然人生已在更新前凍結，共 16,192 個 JSON 存檔邊界。新增職業限 e28，不會由舊種子建立或偽造舊局的新職務。職業、新事件及新增結局一律從新版規則啟用；匿名玩家憑證、版本 3 存檔、角色統計與資料表沿用，不需資料庫搬移。

驗證包含舊局逐步重播、新事件全部選項的自然操作路線與離場後續、四職業的八階職涯、工作事件路由、桌機／手機畫面與伺服器重播。所有新結局另由全結局路線搜尋產生可重播證據。
