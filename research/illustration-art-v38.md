# 人物、場景與結局插畫

本版以內建 image_gen 製作 130 張插畫，再由 Sharp 匯出遊戲使用的圖片。

- 15 位角色依使用者提供的照片重製動畫肖像；翅膀、屎潘蛇沿用既有圖片。
- 40 張場景涵蓋入職、各職業工作、考核、談薪、飯局、休息、夢境、人事通知與公司幻想線。715 段已寫事件及 88 個動態事件 ID 都有映射；舊存檔遇到未知 ID 時顯示辦公室。
- 62 張結局主插畫搭配 13 組獨立繪製的職業道具，輸出 805 張不同的結局圖片。它們是系列插畫的職業構圖版本，並非 805 幅各自從零繪製的主插畫。

私人照片、原壓縮檔、未採用草稿與本機研究路徑均不在公開版本。公開的[提示詞紀錄](illustration-prompts-v38.json)列出採用的提示詞與成品路徑；[圖片清單](../dist/assets/art-v38.json)列出尺寸、大小、來源主插畫、職業道具與 SHA-256。

圖片只讀取目前畫面已知的事件和結果，不改動遊戲引擎、亂數或重播資料。選項按下之前不顯示結果圖；鎖定結局不輸出專屬圖片網址，也不預先載入。圖片載入失敗時仍可閱讀與繼續遊戲。下載離場證明時會內嵌結局圖片；圖片請求超過四秒則輸出文字版。

重新匯出結局圖片：

```sh
npm ci
npm run art:build
npm test
npm run build:check
```

匯出只需要版本庫內的主插畫和職業道具，不需要原始照片、API 金鑰或私人研究檔。

## 人物畫風統一

人物頭像以翅膀既有的粗墨線、誇張臉型與平塗色塊為基準，統一成成人職場諷刺動畫。修正真真、阿福、水蛇、前女友、紅茶、強哥、歐文、山姆、辛蒂與林澤教授十位角色；保留照片中的髮型、眼鏡等辨識線索，減少寫實漸層與精細漫畫描繪。翅膀、屎潘蛇、瑞克、希望、法師、阿良與傑克沿用既有圖片。

本次只更新人物圖片與顯示層，不改遊戲引擎、存檔版本或人生亂數規則。原有 v38 提示詞紀錄保留，修正採用的提示詞另存於[人物畫風修正紀錄](portrait-style-prompts-v39.json)。替換公開人物 PNG 後，可執行 `npm run art:portraits`，只刷新圖片清單中十七位人物的尺寸、檔案大小與 SHA-256，不重新編碼 805 張結局圖，也不改場景、主插畫或職業道具的紀錄。

## 結局插畫畫風統一（v40）

62 張結局主插畫重新依新版人物繪製，統一使用粗深藍輪廓、幾何臉型、誇張表情與平塗陰影，再搭配原有 13 組職業道具重新匯出 805 張結局圖片。結局畫面裡的人物是主插畫的一部分，不能只靠替換頭像更新。這次逐張核對出場人物的髮型、眼鏡、服裝與站位，也檢查主角是否被誤畫成老闆、缺席的人是否意外入鏡。

採用內建 image_gen；公開[結局畫風提示詞紀錄](ending-style-prompts-v40.json)保存提示詞、參考的遊戲資產與成品位置。未採用草稿、生成原檔和本機路徑不進公開版本。`npm run art:build` 可從版本庫內的主插畫重建全部職業版本；圖片清單以 `styleRevision: 40` 記錄本次畫風。

仍在職的成果圖可用作之後離職時的回顧，不代表發生當下已離職。新局的篇章成果、繼續任職與正式離場由遊戲引擎判定；插畫與結局說明不替玩家補選離職。
