# 同事大問答事件改編（e26）

這一版取材自創作者整理的 149 題私人題庫，以及題目附帶的 14 筆圖片。新增 95 場事件、285 種回應，日常總數增至 418，另保留 4 個幻想事件、341 種結局與 118 枚成就。逐題對照現有事件後，將尚未出現的職場片段寫成新場景；同一段故事的不同問法合併處理，已有完整橋段的題目則沿用原場景。

## 改編方式

新篇章涵蓋八小時新人、十分鐘相談、五分鐘拉麵、學歷審查、公積金、調薪、PIP 導師、廣告數據、主管出差、春酒與交接等場合。每場新增事件都有三種回應與各自的選後結果，至少包含一個腦洞選項。角色延續原創肖像與既有別稱；尚未收錄的人物以匿名同事或複合角色出場。故事保留具體的職場衝突、金額單位與否定題的語意，不把錯誤選項當作發生過的事。

猜戀情、個人身體與健康等題材改成職場界線、流言或保護同事的原創情境，不發布私人當事人名單、診斷、生日或憑證。原始題庫、答案表、提供者名單、管理網址與原始圖片均未納入公開 repository。遊戲的對白與結果是虛構改編，不能當成真實事件的逐字紀錄。

## 存檔與抽選

新人生使用 `e26-` 種子，新事件只會加入 e26 的抽選池。舊人生仍可接著玩，事件順序、亂數和選後存檔狀態保持原樣。職業抽選依報到後的實際工作進行；專屬、相關與共通工作的分流規則保持不變。題庫事件仍受一次一場的去重規則約束。

沿用遊戲版本 3、匿名玩家 ID、人物統計與成就資料；不增加資料表、玩家輸入或個資收集。未解鎖結局、成就與待選選項的結果照常保密。

## 驗證

- 從發布中的 e25 程式凍結 341 局、14,114 個完整存檔邊界，逐步核對重播結果。
- 294 條自然路線涵蓋全部 285 種新回應及九種實際職業。新事件的每種回應都從正常開局與玩家操作自然抵達，再驗證合法存檔及可完成的後續；測試不插入事件、職業、數值或亂數狀態。
- 十五場新增多人談話共 33 個合法目標，在事件前、結果後各自核對重播與 API，只有選中的角色會記錄對應的夢境或真實出手。
- 匿名 API 核對進度、結局、成就與人物累計，並測試重送去重、不同玩家隔離及偽造操作被拒絕。
- 九職業、三種可見選項策略各跑 30 局，共 810 局、10,035 次工作事件，已完成工作沒有重複；189 次 PIP 評核都保留三個完整工作回合，每局最多兩次 PIP。這批策略沒有出現 C-level，並非玩家的固定機率。

操作路線可用 `node scripts/find-quiz-v26-routes.mjs` 重新搜尋；所有結局另用 `node tests/find-routes-v3.mjs 5000` 更新證據。最後執行 `npm test` 與 `npm run build:check`。
