# 禾多人生遊戲入口

## Platform

web

## Audience and purpose

Players open standalone browser games from the 禾多人生 game lobby. Each game can take an episode or a recognizable character into its own genre.

## Product commitments

《資料科學大戰》 follows the original Friday data science meeting. The player joins by accident. Contemporary data science, LLM and agent cases interrupt that thread. Traditional Chinese dialogue uses fictionalized writing and drawn characters. Island battles and this game's local save stay independent of career progress.
