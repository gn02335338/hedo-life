一款繁體中文職場黑色幽默遊戲。多種職缺、雙心情、隨機人設、升遷與離場，收集 883 種職業結局與 1,000 枚圖文成就。

## 正式網域與舊玩家搬遷

人生首頁的遊戲區提供移動抽卡遊戲、移動島、禾多 GTA 與禾多暗黑的圖示入口，上方選單保留人生遊戲功能。另有手遊王愛麗絲製作的 [終末之都](https://omegacity-life.vercel.app/) 好友遊戲卡，可另開分頁開始另一段人生。區塊下方另可前往 [BviviFy 首頁](https://bvivify.com/) 及 [旅行行事曆測試版](https://bvivify-pocket-staging.bvstudio.workers.dev/pocket-calendar/)；兩個外站入口另開分頁。

正式入口是 **https://hodo.bvivify.com**，涵蓋人生、移動島（`/island/`）、禾多暗黑（`/arpg/`）、禾多 GTA（`/gta/`）及移動抽卡遊戲（`/cards/`）。原本的 `https://hedo-life.bvstudio.workers.dev` 保留為舊玩家搬遷入口：使用原瀏覽器開啟舊連結，網頁會自動帶走本機存檔、收藏、成就、匿名憑證與待同步紀錄，確認新站寫入成功後前往對應的新網址。舊站資料不會被刪除；已搬過的舊資料不會覆蓋新站後來的進度。

兩個網域沿用同一個 Worker 與匿名史冊，既有玩家 ID、已驗證成就、角色累計及排行榜管理權保持不變。頁尾「搬遷紀錄」可查看／恢復這個瀏覽器保留的搬遷備份。若新舊網址已存在不同進度，搬遷頁會保留兩份並讓玩家選擇，不會混用不同匿名身分的待同步紀錄。瀏覽器禁止儲存或空間不足時，會停留在搬遷頁供重試，原存檔仍留在舊網址。

只有原本保存進度的瀏覽器能搬走其本機資料；已清除的瀏覽器資料或其他裝置不會因此找回。管理員的私人登入 Cookie 不跨網域搬移，需在新網址重新登入。

## 移動抽卡遊戲

[抽卡室](https://hodo.bvivify.com/cards/) 保留 29 位人物、18 件物品與 18 張事件卡，戰鬥改為「牌組冒險」。先選三位人物、一件裝備、一張事件，再從佐證流、摸魚流、場面流挑一種風格。人物各帶兩張專屬牌，搭配基礎牌與事件，組成 13 張起始牌組。

每回合抽 5 張牌、取得基本 3 行動點；可以連續出牌，再決定何時結束回合。先看對手意圖，安排佐證與傷害的順序，或保留行動點處理格擋、補給與抽牌。格擋在對手行動後清空，每場最多 20 回合。物品裝備提供本輪被動；在途中借到同名物品牌時，則依卡面消耗行動點使用，兩種效果分開說明。

十章各有五站路線，途中可選擇戰鬥、休息或事件；戰後從三張牌選一張，也能先不加牌。休息可恢復耐心，或花本輪活動幣升級一張牌；精英戰鬥另給本輪遺物。新牌、遺物與活動幣會改變這輪的打法，借用牌不會直接加入永久收藏。冒險失敗或撤退不扣永久卡片；重新開始會重建這輪牌組。起始卡已有完成十章的驗證見證，成敗仍受抽牌、選路與出牌順序影響。

第一次開冊有 15 張券與 9 張起始卡。各章最終會議的首勝另給券與養成碎片；舊版已領過的章節首勝會保留，不因新版重新發放。重複卡轉成碎片，可升級或製作缺少的卡。N／R／SSR 基礎機率為 70%／24%／6%，十連至少一張 R 以上，累計 20 抽內至少一張 SSR，所有卡池共用保底。沒有現金儲值、交易或付費抽卡。正在進行的舊版戰鬥可以先完成或撤退，再進入牌組冒險。

人生結算頁可自行領取抽卡券，不必留名上榜。伺服器重播完整紀錄，確認至少完成 3 個實際工作回合後，發給 `min(12, 1 + floor(綜合分數 / 1000) + floor(工作回合 / 6))` 張券；報到就離職沒有獎勵。同一局只能領一次，重試或多開分頁不重複加券。

正式卡冊沿用 `hedo-anonymous-v1` 的匿名身分，抽取、養成、出牌與首勝都在伺服器結算。未確認的操作保存在 `hodo-cards-pending-v1`，重新連線會使用原本的操作編號核對；伺服器不採信瀏覽器傳來的卡券、傷害、牌組或抽卡結果。斷線時可另開本機練習卡冊，保存在 `hodo-cards-practice-v1`；練習收藏與正式卡冊分開，不會上傳兌換。兩個本機鍵繼續納入既有網域搬遷流程。

玩法參考與模型驗證見 [卡牌改版紀錄](research/card-redesign-v72.md)。

## 匿名收藏與人生觀測站

角色圖鑑的全站互動排行預設顯示「幻想扁人＋真的被扁」合計，也能分開查看原有指標。每位角色以六邊形雷達圖比較個人與全站已驗證累計：幻想扁人、真的被扁、好感增加／減少的次數與點數。圖表先以各角色自己的完成互動次數換算每100次互動的次數與好感點數，再將各軸依最高比率標準化為0–100指數；個人、全站與各角色共用刻度，切換角色不改變尺度，出場總量不會直接放大圖形。完成互動次數另列，精確原始數字可展開查看；互動不足10次提示樣本較少，缺乏可用互動分母的非零紀錄不推算。缺資料維持未知，本局預覽不混入已驗證圖形。

「這份工作，怎麼結束的？」依遊戲收尾路線統計如何離職，顯示局數與占全站完成局數的比例。自行離職、被要求簽自願離職、公司要求離場、PIP 未通過或通過後離職、冷凍調職、勞資爭議、身心或存款耗盡、創業與退休分開列出；尚未明確離職的收尾另外計數，不公開結局名稱。每局只歸一類，既有完成紀錄也會納入；未知的歷史結局保留為待分類，不需要重玩或額外採集個人資料。

不必註冊。瀏覽器產生隨機匿名憑證，伺服器保存其雜湊與玩家 ID。已完成遊戲由伺服器重播驗證，同一局重送不會重複計數。斷線時仍可玩，待同步紀錄會自動重試。

觀測站顯示匿名玩家數、完成人生數、結局覆蓋數與每日完成趨勢，另以圖表比較應徵與實際職務、改派比例、結局類型、任職長短及月薪區間。新版八階職級、舊五階與乾兒子／乾女兒特殊任用分開統計；PIP、升遷、降薪及崩潰也有發生率。新增指標列明採集起點與有效局數，尚無制度資料的舊紀錄保留為未分類，不用同一個 rank 數字猜職位。匿名玩家數不等於真實人數；統計是休閒用途，不是競賽排名。每日統計使用 UTC。成就保存於同一匿名身分，只記成就 ID 與首次解鎖時間；進行中的成就同步不增加完成人生數。

人物統計另記完成互動次數、想像／真出手次數，以及實際好感增減量與發生次數。翅膀的好感只採用已揭曉選擇造成的變化，排除每日脾氣與臨場運氣；其他角色依當下互動記錄，不把整個團隊的情義分數當成個人好感。三件套的普通共同談話會分別記一次互動；暴走只記實際選中的那位，其餘兩人不跟著增加被扁次數。這些數字不代表真實人物的感受。

人物統計從功能上線起開始驗證收錄。進行中的同一局以延續原分支的紀錄補上增量，重送不會重複計數；已完成的舊局若沒有當時的角色驗證紀錄，不會猜測回補。原有結局與成就仍保留。離線時的當局預覽與已驗證累計分開顯示，未載入的全站資料不會冒充即時數字。

進度存在目前瀏覽器；清除瀏覽器資料會失去匿名身分。不同裝置是不同玩家。頁尾「匿名紀錄」可匯出／匯入圖鑑，帶走已收藏故事；備份不包含登入憑證，匯入收藏不會增加全站統計。舊版 v1/v2 同網址的收藏會保留，進行中的 v1/v2 舊局因規則不同不會轉換。v3 的既有局則沿用原規則；e21 新局保留八階職涯、能力取捨、心情體力波動、崩潰、消費、獨立談薪與 e20 人事流程，再加入職業專屬工作與新的工作抽選安排。e20 與更早局保留原本的事件池、歷史、亂數序列與重播結果；e19 與更早局不插入 e20 人事事件或水蛇對話，e18 與更早局也不插入談薪。

遊戲紀錄不要求姓名、Email 或真實學歷，不保存原始 IP、選擇內容或亂數種子。驗證時會暫時重播操作紀錄；伺服器保存人生與玩家的綁定、種子及操作序列的雜湊、已驗證操作數與角色累計，不留操作原文或對話。個人角色累計須用本機匿名憑證讀取，全站只公開合計。匯出的圖鑑含本機成就、不含匿名憑證；匯入只算本機收藏，不會變成伺服器已驗證紀錄。主動投稿另存私人佇列，防濫用使用短期連線雜湊；公開 Issue 不附匿名玩家 ID。詳細欄位、保留期限與限制見 [Worker 說明](worker/README.md)。

公司本島保留七個部門與共享園區；球場、居酒屋、阿良行程、醫院與警局位於下班生活島。流放島獨自在遠海，設有看門值班亭與冷宮。五島之間沒有步行橋，各島岸邊都有實體候船碼頭、目的地路牌與停泊渡船。總覽可點地圖上的「⚓ 搭船旅行」，散步時走近碼頭按 E／空白鍵或「搭船」登船；首頁同名入口也保留。經過航程後才能靠岸。清單、人物定位、導覽與舊場所連結也使用同一個渡輪入口；選到遠方地點時不會直接傳送。無法顯示 WebGL 時，清單仍保留登船與抵達流程。

Oneira 島是與 [Oneira](https://oneirahub.com/) 相連的友好專案島，位於獨立海域，從原三島都能搭船往返。靠岸後可從航站或園區名片走進固定的 Oneira 官網碼頭頁；Oneira 首頁與碼頭頁提供回程。回程網址只帶公開來源標記，移動島會從 Oneira 碼頭播放返航主島的航程，確認靠岸才打開主島內容。兩站不交換匿名憑證、職涯存檔、戰績或申請資料，不接受網址提供的任意外站目的地。Oneira 不開放移動島定居申請，原九個生活園區與 27 個名額保持不變。

終末之都島是手遊王愛麗絲製作的 [《終末之都｜OMEGA CITY LIFE》](https://omegacity-life.vercel.app/) 友好遊戲島，設有霓虹城市天際線、市民登記站、城市觀景台與自己的實體碼頭。可從其他四島搭船抵達，靠岸後從航站或園區名片另開遊戲官網；移動人生首頁也有獨立入口。外站網址固定，不帶玩家身分、匿名憑證或職涯進度，兩款遊戲各自保存資料。終末之都島不開放定居申請，島內回話是原創迎賓故事；外部遊戲維持原作者的版本，未加入外站回程或共用存檔。

點「開始散步」，以 W A S D、方向鍵或手機方向盤移動，靠近場所入口後按 E／空白鍵或互動按鈕。總覽點園區會顯示場所標記與清單，也可直接搜尋部門或用 `#mis-service` 等場所連結探索。34 位公開同事有各自的偶遇與 102 種回話；名冊分別顯示工作據點及目前所在園區。對話與清單開啟時停止玩家移動，Home 或「看全島」返回地圖。無法顯示 WebGL 時仍可從清單探索全部場所與人物。本機啟動後開啟 [移動島](http://127.0.0.1:4173/island/)。

34 位正式人物依小島時間安排作息：一般同事白天在自己的工作部門活動，午間與午後分批到茶水間休息，休息後回部門，18:00 後各自去球場或居酒屋。阿良在 19:00 揪傑克、辛蒂、詹姆士與強尼到夜色碼頭，19:30 起沿碼頭散步，20:00 後回到各自的下班安排。這些是虛構的島上作息，不代表真實人物的行程。切換時間只改變目的地，人物在島內沿安全小路與橋樑行走，跨島會先到碼頭搭船，途中會等路、讓路；名冊會分開顯示目前位置和前往的場所。人在航行時，名冊顯示航線，靠岸後才能聊天或定位。「看看位置」跟隨人物當下的位置，園區人物清單也會隨到訪與離開更新。核准的新島民仍在申請的區域散步。

愛麗絲平常在終末之都島的市民登記站接待，休息與晚間去城市觀景台；傑克在 Oneira 航站、強尼在開源靈感館活動，休息時在兩個場所間換個位置。三人的原公司部門與角色故事保留，名冊另標示專案島接待據點。傑克、強尼仍在 19:00–20:00 參加阿良行程，散場後沿碼頭搭船回 Oneira。其他同事仍照原作息；三人若送醫、做筆錄或被流放，也先完成處置再回各自的專案島。

玩家靠近時，同事會停步轉向玩家；按 E／空白鍵或「聊聊」開始對話，對話中的人物會留在原地，關閉後等玩家離開再繼續。首頁「島上此刻」顯示作息與活動，並提供阿良的晚間邀約；可以參加、先問安排或婉拒，選後才揭曉回應。原本的同事故事會清楚標為回憶，不冒充移動後所在地的新事件。無法顯示 WebGL 時，仍可查看預定行程與邀約，不將預定目的地標成即時位置。

小島從 10:00 開始，播放時每 4 分鐘前進一小時；五個時段按鈕可直接看上班、午休、茶水、下班與揪團。手動切換後停在選定時間，按「播放」才繼續。暫停、減少動態偏好及離開分頁會停止人物位移與時間流動；閱讀對話或進行導覽時也暫停自動時間。返回分頁不補跑離開期間的作息，玩家仍可在暫停時散步聊天。六角區域、步道與花圃等生活小景皆為原創；[參考觀察與設計取捨](research/island-life-reference-2026-10-25.md)記錄了 REA、動物森友會與卡坦島的參考範圍。

原本九個園區保留區域 ID，新增流放島、移動醫院與島上警局；沿用 `hedo-island-v1` 鍵名與版本 1 格式。園區足跡持續保存，舊版回話紀錄保留原值，不把舊選項索引當成新版故事的回答。新版園區與場所回話、場所探訪、同事偶遇及阿良邀約回應只存在本次頁面記憶體，重新整理後清空；這些對話不改動職涯存檔。公開島民名冊由既有 API 載入；只有主動送出上島申請時，才沿用或建立既有匿名憑證。場景使用本機 Three.js 0.180.0（[MIT 授權](dist/island/THREE-LICENSE.txt)）；對話、場景幾何與介面皆為原創。[資料行為](worker/README.md#the-moving-island-static-experience)另有說明。

首頁「故事挑戰」把對戰串成五章同事故事與經營總部的後續。先在故事模式真正勝過全部 31 位普通同事，才能依序挑戰乾兒子、董事長與翅膀；完成後碼頭還有一封神秘邀請。從人物對話選對戰也會檢查相同解鎖條件。故事切磋不產生送醫或警局處置；輸、平手、取消與重複勝利不多算通關，已贏的頁面保留，可失敗重試。一般「打架」的勝負不會補算成故事戰績。

故事勝場與邀請保存在獨立的 `hedo-island-challenge-v1` 本機索引及逐場紀錄，不改寫小島護照、匿名身分、職涯重播或伺服器收藏。同瀏覽器分頁會合併已完成勝場；舊網址搬家也保留這些紀錄，同一匿名身分的相容進度可合併，不同身分仍由玩家選擇保留哪份。清除瀏覽器資料會移除本機故事進度；不能儲存時會提示，仍可玩完本次挑戰。

「我也想申請上島」讓玩家填暱稱、區域、六款服裝色、招呼、自我介紹與私人申請理由，預覽公開名片並勾選同意後送件。在同一瀏覽器可查詢審核結果、撤回待審申請或讓已核准角色下島。首頁「島務管理」顯示公開的待審核總數，前景每分鐘及返回頁面時更新；讀取失敗顯示「—」，不誤報為零。申請內容不會自動公開或轉成 GitHub Issue；[島務管理](https://hodo.bvivify.com/island/review/) 沿用現有管理員密碼，核准後角色才出現在地圖與「新島民」名冊，走近可觸發對話。原本九個生活園區每區最多三位、合計最多 27 位新島民；流放島、醫院與警局供事件使用，不開放申請定居；名額用完時不會覆蓋原本角色。申請理由與審核備註只供本人及管理者查看，不收聯絡方式或照片。清除瀏覽器資料會失去申請管理憑證；未通過或已撤回內容保留至結案 90 天後清理。

島嶼測試涵蓋地點、公開角色與偶遇、回話結構、導覽連結、獨立儲存鍵與損壞資料處理，以及鍵盤／觸控輸入的組合、釋放與中斷：`node --test tests/island-*.test.mjs`。完整驗證仍使用 `npm test` 與 `npm run build:check`。

流放島設有看門值班亭與冷宮，醫院有急診室，警局有筆錄室。與官方同事對話時可選吵架，或開啟「移動島大亂鬥」一對一即時遊戲。用 W A S D／方向鍵走位，按住 J 連擊、空白鍵閃避、K 放蓄力大招、L 丟撿到的紙團；手機提供搖桿與四個動作按鈕。玩家與 34 位同事共用圓頭、點眼、短四肢的 Q 版人物畫法，依公開插畫轉譯各自的髮型、衣服、眼鏡與隨身道具；傑克改為黑色運動 T 恤、灰色運動褲與球鞋，翅膀穿粉色 Polo、左腿約為右腿一半並持拐杖，屎潘蛇配圓眼鏡；島上 3D 人物也同步兩人的造型。上方恢復原人物插畫頭像，傑克使用新繪製的運動版。34 位角色各有開場白、至少三招技能及一個專屬事件，合計 119 招與 34 個事件，改編自已公開的史冊、問答情節與職稱。招式包含扇形近戰、直線衝刺、投射物、鎖定落點、減速、可打斷回血與有時限的護盾；低血反應優先觸發，每局限定事件不重複。翅膀的黃金左腳、紙板三樓落點與檀香補給，阿福的舊傷躺平與披薩，皆有對應姿勢、預警、實際數值和反制方式。對戰下方可展開招式說明，閱讀時會暫停。[角色招式改編紀錄](research/island-signature-skills.md)列出公開來源與範圍。對手出招有扇形提示，連擊、氣勢、紙團與場地障礙都會影響戰鬥。75 秒內擊倒對手，或到時比較剩餘體力；完全相同算平手，不新增處置。勝敗依實際操作結算，不另抽結果。打架敗方送醫、勝方送警局，玩家與對手都會實際轉移；與翅膀或屎潘蛇吵架，玩家也可能收到流放通知。事件中的人物會暫停原作息，調整時鐘不會解除處置；完成包紮、筆錄或流放交班後，玩家可恢復互動，也能陪同事辦理手續，讓他沿路回到當下的作息。這些是虛構的島上插曲，僅保留本次頁面記憶體，不寫入職涯、匿名史冊或申請資料。Esc／P 或右上角暫停鈕可暫停；切換分頁或失焦會停住對戰，返回後手動繼續，不補跑離開時間。開打前可直接關閉，開打後離場先提供繼續或認輸，認輸依敗方送醫收尾。未完成與舊場回呼不能重複結算。WebGL 無法使用時仍可玩獨立的 2D 對戰；若連 2D 畫布也無法開啟，會提供重試而不捏造勝敗。[REA 參考與取捨](research/island-brawl-reference-2026-10-26.md)記錄了操作觀察與原創實作範圍。

## GitHub + Cloudflare

GitHub 保存公開程式、版本與 Issues。Cloudflare Workers 同時提供靜態頁面與 `/api/*`；SQLite Durable Object 保存匿名收藏及統計，不需另設 D1、KV 或外部資料庫。

```mermaid
flowchart LR
  G[GitHub 原始碼] --> D[Wrangler 部署]
  D --> W[Cloudflare Worker]
  B[玩家瀏覽器] --> W
  W --> A[靜態遊戲頁面]
  W --> S[SQLite Durable Object]
```

以自己的 Cloudflare 帳號登入後部署：

```sh
npx wrangler login
npm run deploy
```

本 repo 已啟用 GitHub Actions 自動部署：推送到 `main` 後，會先安裝鎖定依賴、通過測試，再部署到正式站；測試失敗就不會部署。PR 執行檢查但不部署，其他分支也不會部署。也可在 Actions → Deploy to Cloudflare 選擇 `main` 手動重跑。每次成功部署摘要會附上正式網址、commit 與執行紀錄。

部署憑證放在 GitHub 的 `CLOUDFLARE_API_TOKEN` secret，只授權 `hedo-life` 的 Individual Workers Editor；帳號 ID 使用 `CLOUDFLARE_ACCOUNT_ID` secret。要暫停自動更新可將 repo variable `CLOUDFLARE_DEPLOY_ENABLED` 設為 `false`，現有正式站不受影響。Token 無自動到期日；需要停用時可在 Cloudflare 撤銷專用 token。請勿把憑證寫進程式碼。

Fork 到自己的 repo 時，請自行設定上述兩個 secrets、啟用 `CLOUDFLARE_DEPLOY_ENABLED=true`，並修改 Worker 名稱與正式網址。

## AI 修 DB（e31）

實際職務為 AI 工程師的新人生，工作日有機會遇到資料匯入故障。三個選項包含正經查修與替資料辦報到的腦洞做法；做出選擇後，才會揭曉「AI」到底在做什麼，並取得專屬圖文成就。主鍵自動編號本身是正常功能，這段笑點放在把它當成 AI 模型的說法。

助理任用成就更正為「多兩個字，少一份薪。」；原 ID、已收藏的日期與解鎖條件不變。新版共 123 枚成就，未解鎖的名稱、插畫與條件繼續保密。全部 545 條 e30 舊局與 24,245 個存檔邊界維持一致，新增事件只進入 e31 新人生。


## 起薪低於 30K 的提醒修正

原本的提醒只看選擇前後是否真的降薪，漏掉了起薪就是 27K 的行政專員，也漏掉在履歷產生時已折薪的助理任用。e28 以後的有效低起薪存檔，在「繼續人生」或看完結果、回到安全工作場景時，會補上法師的私下談話，不必重新擲履歷。

談話以一個可驗證的 `salary-advice` 操作加入存檔。舊操作紀錄仍照原路重播，匿名身分與收藏不變；尚在報到、查看結果、人事通知、情緒失控或其他談話時，等流程結束再提醒。回應後回到原工作，不多耗一天、不減 PIP 天數，也不重抽工作事件。起薪與後來降薪各用自己的文案，避免出現「27K 改成 27K」或憑空多出降薪通知。


## 開嗆也算一個回答

新版按鈕會顯示當場要說的台詞，結果頁另以「你說」框呈現，方便分清玩家與對方的話。報到時，照原職任用、改派與助理任用各有不同台詞；三件套同場時，也能看清楚要對哪一位開口。

開嗆後會進入對應後續，不再每次回到原本三個選項。一般工作把這句話當成第四種回應，只結算一次工作日、PIP 倒數與收入；報到可能當場被終止任用，若新職稱或薪資尚未確認，仍會明問要不要留下。降薪、PIP、升遷與其他需要正式決定的場合，各有爭執後的回應，不會用一句嗆話代替接受條件。

## 排行榜與結算留名

第一季採用目前七種互動活動已啟用的人生規則，種子前綴為 `e39-cal46-kin49-g-e-s-m-`。舊規則的人生仍可查看結算分數，正式榜請開一段目前規則的新人生；已完成且仍保有完整操作紀錄的本季人生也可參賽。目前計分版本為 2，不隨全站結局熱門程度改分。

綜合滿分為 10,000 分，所有數值均由伺服器重播後計算：

| 項目 | 最高分 | 計算方式 |
| --- | ---: | --- |
| 三項能力 | 3,000 | 最強一項占 60%，三項合計占 40%；合計以現行總上限 180 換算，三種專精同等計分 |

除「完成工作」外，其餘五項都乘上經歷比例 `min(完成工作回合 ÷ 19, 1)`。報到就離職是 0 分；19 個工作回合後取得這五項的完整權重，完成工作的 2,000 分則需做到 23 回合。初始能力、尚未消耗的心情與起始高階職稱不會讓短局直接拿高分。既有留名紀錄會由保留的已驗證數值重新計分，保留暱稱、公開識別碼與首次留名時間；移轉完成前不混排新舊分數。

單項榜另列各數值、完成工作回合、惡言相向、真的出手、幻想出手與升遷次數。這些次數只認已結算的遊戲紀錄，不把點選單、尚未揭曉的動作或敘述中的提及算進去；開嗆與出手不額外加進綜合分數。

結局頁會先顯示分數與圖表，再提供 2～16 字的公開暱稱輸入。按下「留名，加入排行榜」才會刊登，不需另勾同意框；連線失敗不顯示成功，也不會自動補送留名。可以修改暱稱或撤下該局，撤榜不會刪除匿名收藏、成就或全站統計。公開榜只顯示暱稱、職業、分數、完成工作回合與刊登時間，不公開結局名稱、劇情、遊戲操作或匿名身分憑證。暱稱由玩家自選，請勿填入真實個資。
